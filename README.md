# AQUANOVA – Smart IoT-Based Aquaponics System

AQUANOVA is an IoT-based smart aquaponics system designed for real-time
monitoring and intelligent management of fish and plant growth.

The project integrates embedded systems, sensor technology, IoT,
automation, Firebase-based data management, and digital-twin concepts
to support smart and sustainable aquaponics.

## Technologies

- ESP32
- IoT
- Sensors
- Firebase
- Web Dashboard
- Digital Twin
